# Public input consumption

- adaptLegacyReport report: require non-null non-array object before properties; schemaVersion uses strict equality to integer1 and constant rejection text; required pass/issues/change/digest fields preserve explicit named refusal. Digest container must be an object, sourceTree a sha256 string. stableStringify handles legal JSON recursively without value-to-string coercion.
- Shared validateIdentity: require object before any property/spread; runnerId/execution/environment non-empty strings; optional toolchain/reportPath non-empty strings; optional now/expiry valid primitive timestamp strings before Date.parse. Default expiry also checks representability. Objects/arrays/null/numbers/booleans are never coerced to strings or clocks.
- admitLegacyReport payload/options: validate object before destructuring/property access. Protected requireManaged remains boolean-only and true rejects before reading worker content or issuing dispatch. Identity uses the same preflight before spread; top-level clock overrides identity.now only if explicitly supplied and follows the same validation.
- Authority/current: require actual issueDispatch/verifyDispatch code functions and object current binding; current input/policy must be sha256 strings and environment non-empty string. This validates shape, not OS provenance.
- Dispatch/replay: require object dispatch; optional run/gate/role primitive non-empty strings, role from the existing native three-role domain, optional input/policy sha256 strings, attempt/epoch positive integers. issuedExecutions must be an array of non-empty execution strings. Every malformed fixture is refused before dispatch count increases. No new flow taxonomy is created.
- CLI: file read/JSON parse failures use constant trusted labels instead of raw native ENOENT/JSON.parse messages; invalid TestContract uses static version/field refusal. No schema or Gate change. Existing mechanical0/input1/blocked2, component scope, protected managed refusal and optional tool tripwire remain covered by the original25 tests.

Boundary: legal JSON values are covered. Exceptions raised by arbitrary injected protected code are not caught and mislabeled as successful input validation. No catch-all TypeError adapter, tolerant string conversion, schema relaxation, new authority or controller was introduced.
