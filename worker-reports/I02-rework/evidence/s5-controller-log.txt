Usage: comet [options] [command]

Agent Skill Harness For Turning Ideas Into Evaluated Workflows

Options:
  -v, --version                  Output the current version
  -h, --help                     Display command help

Commands:
  init [options] [path]          Initialize Comet workflows and Agent
                                 integrations in a project
  status [options] [path]        Show active changes and workflow status for a
                                 project
  task [options] [path]          Select context for a regular Comet Skill task
                                 and record its outcome
  workflow                       Resolve whether /comet should use the
                                 configured Native or Classic workflow
  memory                         Inspect and maintain personal memory across
                                 sessions
  knowledge                      Inspect and query Project Knowledge for the
                                 current project
  resume-probe [options] [path]  Determine whether the current request should
                                 resume an active Comet workflow
  dashboard [options] [path]     Launch the local Comet Dashboard in a browser
  doctor [options] [path]        Diagnose Comet installation health and
                                 repairable issues
  update [options] [path]        Update Comet and its installed Skills, Rules,
                                 and Hooks
  uninstall [options] [path]     Remove Comet Skills, Rules, and Hooks from
                                 project or global scope
  eval [options] [target]        Evaluate a Skill or eval manifest and generate
                                 results
  state [args...]                Read or update Classic workflow state
  guard [args...]                Validate Classic phase requirements; --apply
                                 advances after checks pass
  handoff [args...]              Create or inspect Classic workflow handoffs
  archive [args...]              Archive completed Classic workflow changes
  check [args...]                Execute and record Classic build or
                                 verification checks
  classic [args...]              Manage the Classic workflow and its configured
                                 artifact root
  native [args...]               Manage the self-contained Native workflow
  skill                          Install, inspect, and debug local Skill
                                 packages
  publish                        Review, approve, publish, and distribute Skill
                                 Creator candidates
  creator                        Create or resume Skill Creator candidates for
                                 /comet-any
  bundle                         Manage advanced /comet-any Bundle state and
                                 audits
  help [command]                 Display help for a command
