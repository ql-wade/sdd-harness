# Fixed Spec Adapter host seam

Production bootstrap must verify and bind the **same installed** manifest-pinned original aggregate used by the Comet Run. `createManagedSpecAdapter({runtime,projectRoot})` captures that aggregate's `runClassicCli` function and canonical project root. `runtime` is a protected code parameter, not configuration, a worker response or a module-path choice. Function injection itself proves no source/OS qualification.

- `inspect({change})`: pure target-summary/scenario inspection and original persisted Run identity. No dispatch, receipt or approval.
- `closeout({change,expectedSummaryDigest?})`: optional inspected-summary drift check, current scenario preservation, then original top-level `archive` with **undefined handlers** and the fixed root/cwd. Native checks current RATPV/Kp, authority, tool closure and operation transformation. Successful result additionally requires physical archive location and independent main-spec readback. No second sync.
- `recover({change})`: original `state next` on the same Run, then independent identity/location/readback. No adapter retry queue and no direct archive shell fallback. A waiting Run remains waiting until actual current Kt/other Native obligations permit original reconciliation.

Native response bytes are retained in `native`; observed `status` is original lifecycle state, not a new adapter state. `overallCompletionEligible:false` means this component cannot sign overall delivery; it does not prevent the original Comet from legitimately completing after current obligations. Native current-integrity faults remain refusals even if historical status is completed.

Missing current Run/ambiguous location fails closed. Comet ownership metadata (including malformed config/control/history) rejects legacy direct writer, recovery, lock helpers and rehearsal-copy entry points. Plain non-Comet compatibility cannot qualify a managed gate.

Production uses the existing P2_4 fixed host/authority/context/policy/collector/review bindings, original tool byte manifest and short-lock/long-IO/short-lock transaction. No SDK or port interface was added here. Actual authenticated role launch, P2_5 semantic consumers, I01/I02 qualification, real Kp/Kt, OS boundaries and protected bootstrap installation still belong to their original owners. The local test fixture never establishes those facts.
