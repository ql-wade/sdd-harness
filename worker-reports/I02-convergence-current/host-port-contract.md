# I02 physical CLI code port

Import createCliJobDriver from the fixed installed tools/infra/runner.mjs. Only P1_3 protected CODE constructs it with `{authority,registration,dockerExecutable,dockerSha256}`; no job/env/module loader chooses it. authority supplies existing verifyDispatch; this driver never calls issueDispatch. Registration fields are documented by Authority example physicalProcessBinding.registration; actual identifiers/principals must be independently qualified, not filled to satisfy shape.

Registration binds project/authority/workspace/namespace/engine/context/image/sdk+bootstrap digests, six container-role mappings, distinct workspaces/control volumes and expected principals. The constructor copies it. A signed current ActionBinding inputs must include canonical digests `runner-registration`, `runner-role-binding` and `runner-job`. Job is exactly `{schemaVersion:1,execution,run,argv}`; image/role/principal/volumes/consumer/phase fields are refused. argv is opaque data for the fixed host, never Node loader args or a shell command. Fixed host selects the officially bound version public factories/API and independently verifies current eligibility before invoking this port.

`startCliJob({dispatch,currentActionBinding,job})` validates scope before Docker, checks engine/image/volume metadata, creates only the fixed role name with narrow mounts/flags, writes one bounded JSON input frame to the immutable host entry and returns `{handle,clientProcessId,terminal}`. Existing same execution is observed rather than relaunched; a mismatching role slot refuses. Unknown transport/creation is not proof of absence and does not trigger internal retry. Fixed bootstrap must consume one original frame and reconcile unknown results; no new0.4-private bootstrap is implemented here.

`observeCliJob({...originalRequest,handle})` and `stopCliJob({...originalRequest,handle})` verify the original ownership tuple, engine, image/labels/UID-policy/cwd/mounts before observation or stop. Source host retains the original protected registration/action snapshot for old owned executions when it needs readback/cleanup; only active current eligibility may start new work. A worker proposal cannot supply that snapshot or choose another container. Stop is only the exact original execution, does not remove resources or claim phase completion.

Terminal is the Docker client process result with raw stdout/stderr buffers and truncation/unknown status, not a Gate verdict; source host must read actual container status and original result before semantic admission. Observation timeout is not process death. The adapter stores no durable process business state, phase, DAG, queue, retry or authorization ledger. Docker labels identify a registered process and never prove real model principal identity. P1_3 owns fixed bootstrap, actual source identity/credential eligibility and controlled result return to the same Comet; I02 owns physical isolation and process observations.

Runtime field naming is transport data, independent of Comet internalRunState. Existing6da fixture tests are finite construction evidence; official-version rebind and actual image/tool/channel qualification are mandatory before enabling any product use.
