# Public input and caller audit

- freeze/init/admit/tally/finalize/judge validate package identity, immutable quorum/thresholds/criteria, run directory input and integer round before the Python command. Review IDs cannot escape evidence root; regular artifact is canonicalized to the same real path the original Python gate uses.
- Explicit grill input is validated before run creation; closure uses literal booleans, nonempty resolution and unique IDs. All new managed inputs validate object/array/element shapes before iteration. Shared ActionBinding/TestContract validation uses the existing contracts; SDK performs current source/collection admission.
- Managed T reads raw result/trace JSON up to 1 MiB. Invalid version/root, case/check/oracle/material/environment/cleanup/findings, unbound source or raw bytes cannot be promoted by summary/strong/pass. A binds exact authenticated sources, original bytes and current mechanical files.
- Python execution is fixed review_gate.py with 30-second timeout and 1 MiB output bound. Missing dependency/failed mechanical output is nonzero; no model CLI fallback. Three rounds remain the existing policy.
- Duplicate ballot admission preserves byte-identical evidence; changed ballots require another round. Finalize conclusion/plan/report are not overwritten by a retry. Fresh verification uses temporary output and cleans it in finally.
- `consumeArchitectureGate`, `consumeTestDesignReview` are the existing public seams. Their owned adapter tests and 2_5 delivery case consume the new protected context. Existing P3_2 direct compatibility callers are finite component evidence and are outside this owner; no changes or historical ballot replays were performed here.
- Parent SDK, formal Comet patch/lock, live configuration, registry, grants, task/DAG/ledger, old reports and actual knowledge stores were not mutated. Native fixtures use only private temporary project roots; raw audit snapshots are ignored test evidence, not another product state source.
- Stale/corrupt/unknown direct library inputs fail closed. Expected mechanical native exit semantics are retained; input errors use explicit code errors and the enclosing existing CLI remains responsible for 0/1/2 formatting.
