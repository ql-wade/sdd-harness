# Sync: 进程清理修复（2026-10-20）

## 修复内容
`dispatch_round.py`:
- `start_new_session=True` — zcode/claude 子进程在独立进程组
- `_kill_process_tree()` — `os.killpg(SIGTERM→SIGKILL)` 杀整棵进程树（替代只 terminate 单进程）
- `_sweep_orphan_zcode()` — 超时后清扫残留 zcode-cli 进程

`ralph_loop.py`:
- `atexit.register(_cleanup_live_processes)` — 取消/退出时自动清扫
- dispatch `subprocess.run` 加 `start_new_session=True` + 超时时调用 `_cleanup_live_processes()`

## 问题
zcode 0.17.0 的 app-server 模式产生子进程树；旧代码只 terminate 主进程，子树（zcode-host、Electron helper）存活为孤儿。22+ 轮评审后累积 10+ 个残留进程。

## 验证
run-23~26 三方评审正常完成，退出后 zcode-cli 进程归零。
