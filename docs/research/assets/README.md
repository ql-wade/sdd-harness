# 架构图生成约定（用户确认的工作方式）

- 架构/路径图用 codex 内置 `image_gen` 生成：`codex exec --skip-git-repo-check --sandbox workspace-write -C <输出目录> - < 提示词文件`，提示词中明确"使用 imagegen 技能的内置 image_gen 工具"并指定目标文件名。
- 信息密度优先：竖版海报、分层区块+标签芯片，提示词逐条列出全部要呈现的文字（不靠模型自行发挥）；只画最终架构，不呈现"已退休"内容。
- 生成后必须目检/逐字校验（图像模型易乱码），通过才引用；改版用新文件名（v2/final），不覆盖既有版本。
- 本目录产物均为提案配图；进正式架构文档前建议补确定性 SVG 源（位图文字不可 diff 审计）。

现有产物：comet-architecture-0.5.0-final.png（最终架构，提案 §8 主图）、comet-delivery-flow-v3.png（交付执行流程·技能×机制，提案 §8.2）。生成教训：图像模型对英文连字符词与斜杠易渲染错字（v2 曾把 grill-me 混入中文字、斜杠画成"井"），提示词需把英文标识符集中列举并显式纠错，生成后必须逐字校验英文词。历史版本已按用户指示删除，只保留最终态图。
