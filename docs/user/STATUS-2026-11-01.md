## 架构（一段话说清）

一次交付 = 一个 **change**（`openspec/changes/<名>/`，名字即 Run id），由 **Comet 0.5.1 运行时**做唯一主控，沿六道管理门 R→A→T→P→V→Kp 推进到归档。每道门需要**证据收据束**（`.sdd/delivery/gates/<门>/receipt-bundle.json`，HMAC 签名链），签收者身份与作者/构建者互斥（门禁强制）。人（你）只在**审批点**做真实决策；技能工作由代理执行。归档后 Kt（团队知识）发布到外部知识库。
