# 总体状态与更新评估（2026-11-01）

## 架构（一段话说清）

一次交付 = 一个 **change**（`openspec/changes/<名>/`，名字即 Run id），由 **Comet 0.5.1 运行时**做唯一主控，沿六道管理门 R→A→T→P→V→Kp 推进到归档。每道门需要**证据收据束**（`.sdd/delivery/gates/<门>/receipt-bundle.json`，HMAC 签名链），签收者身份与作者/构建者互斥（门禁强制）。人（你）只在**审批点**做真实决策；技能工作由代理执行。归档后 Kt（团队知识）发布到外部知识库。

## 需要更新的（按优先级）

1. **指南合流**：使用指南（含 state init 一行命令、presets、隔离选项）在 `preserve-pre-rewrite@a187743`，纯交付线上没有——需把它合入交付线并按 r34 实证补一章（share-link 取证、r10+ 全程驱动脚本、材料化三形状）。
2. **Outline 传输包装固化**：Kt 发布的 ~40 行 fetch 包装是会话内临时实现，应固化进 `lib/adapters/outline.js`（协议层已有、缺传输），带 OUTLINE_BASE_URL/OUTLINE_API_KEY 环境变量与 429/502/503/504 重试。
3. **llmwiki MCP 修复**：tools/call 挂起 = server 向 stdout 写了非协议输出（规范要求日志走 stderr、消息单行 JSON）——owner 波次。
4. **上游运行时两件**：归档后 deliver 簿记的枚举歧义（自举 scaffold 豁免 + 最小树枚举）；record-outcome JSON 通道字节材料化第四形状（需对解析器插桩）。
5. **驱动器固化**：/tmp 的 r4-driver.mjs 与 r12-all.sh 是实证过的旅程驱动器，应入库存档（tools/），否则重启即失。
